# Sprint 2 — Prism Notes — 2026-02-12

## What Was Built
Standalone Canvas Chat App (`prism-canvas-app/`) — complete Android project.

## Architecture
- **Model**: `ChatMessage` (data class), `CanvasState` (with computed `canSend`, `messageCount`)
- **ViewModel**: `CanvasViewModel` with `MockAgentBackend` streaming token-by-token
- **UI**: `ChatScreen` → `ChatBubble` (with spring entry animation) + `InputBar` (Enter + Send button)
- **Theme**: Material3 Dynamic Color, dark mode support

## Tech Stack
- AGP 8.4.0, Kotlin 1.9.23, Compose BOM 2024.01.00, Gradle 8.6
- Target API 34, minSdk 29
- Compose Compiler 1.5.11

## Tests (18 passing)

## Build Environment Note
ARM64 server (gx10-1) needs `qemu-user-static` + `libc6-amd64-cross` + `libgcc-s1-amd64-cross` + symlink `/lib64/ld-linux-x86-64.so.2` for AAPT2 (x86_64 binary). Set `QEMU_LD_PREFIX=/usr/x86_64-linux-gnu` when building.
