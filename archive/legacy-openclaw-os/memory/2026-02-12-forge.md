### Key Decisions
1. **Kotlin over Java** — Modern, null-safe, coroutines. No debate.
2. **Interface-first architecture** — Every component is an interface with a stub implementation. Swap real implementations in without changing callers.
3. **Graceful degradation** — Cloud → local inference → offline queue → phone still works as phone.
4. **SSE for cloud, WebSocket for home server** — Match the transport to the use case.
5. **SecurityManager as mandatory gate** — Every tool call goes through security check. Always.
